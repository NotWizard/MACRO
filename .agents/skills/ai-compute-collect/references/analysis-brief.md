# 算力经营研究写作口径

读者要在一屏内分清三件事：**盈利是否已经下滑、现有指标是否提示放缓、什么观测会证实或推翻判断**。不要用股价涨跌、新闻传闻或“产业景气”代替经营证据。

## 先做比较，再写判断

1. 每块先找到最近**可比**的一期和比较期。核对财季、发布日、币种、GAAP/非 GAAP、企业与分部口径。跨公司先给样本内比例或有代表性的分歧，不把错开的财季说成同期。
2. 每块选 1–3 项真正影响结论的观测，写清“谁、哪一期、从多少到多少”。同时查一项能反驳它的证据；找不到反证或比较期就直说，不硬凑。
3. 分开写水平、增速和预期修订。既有披露只能支持“到这个日期，观测为……”，不能直接推出未来变化。上下游方向一致可提高把握，不能单凭同步认定因果。
4. 给读者一项下次能回读的观察：哪家公司/指标、哪个披露窗口、看什么方向。明确它在什么条件下会改变判断。写“继续关注市场变化”不算。

## 六块各回答一个问题

| 板块 | 当前需要回答 | 下一步验证 |
|---|---|---|
| 盈利现状与预期 | EPS 绝对水平、同比增速和利润率是否同向？是增长减速、实际盈利收缩，还是收入/利润被税项、一次性项目或股数扰动？指引和同目标期 EPS 共识独立论证；没有多版本共识就写未知。 | 下一次财报看同口径 EPS、营收和营业利润率；存在可比预期才跟踪同目标期的修订方向。 |
| 客户需求与资本投入 | 现金资本开支是在加速还是放缓？先对照同一公司的单季现金购置与其公司口径，再核对云收入、利润和现金流有没有跟上。公司口径可能计入新增租赁或还本；集团支出不能叫作纯 AI 支出。 | 分开看购置、租赁与投入指引；云利润率及合同履约用于交叉验证，不把集团投入机械归因到某个分部或用 RPO 代替消费。 |
| 制造与交付 | 新订单能否接上、在手订单什么时候能交？先对照同公司同业务的新接、期末余额和已确认收入；再用 ODM 三月合计营收与上游量产窗口交叉检查。营收受售价、汇率和组合影响，纬创和纬颖不加总。 | 看新接是否连续走弱、在手订单中有没有取消或推迟、确认收入能否跟上。积压上升也可能是交得慢；只有排期证据时注明日期和范围，不写成订单金额或已兑现。 |
| 算力租赁 | 同一 SKU、同源同配置的长短期价差在说什么？先确认时间、价格类型及样本是否改变；挂牌中位数和合成基准各自解释，不拼接。 | 同一样本持续变化后，再看样本数和固定配置报价能否确认；没有成交、容量或利用率证据就不外推。 |
| 电力与部署 | 订单、设备计划交期、实际交付、接电和投运现在进到哪一步？非连续交期写清产品、地区、日期和计时起点；容量和实际负载分开。 | 查同型号的下一版排期，以及一个项目的设备到场/并网窗口；未披露不等于瓶颈消除。 |
| 库存与盈利质量 | 备产、产成品积压与回款谁在变化？用同公司同期库存分类、周转与经营现金验证；缺分类或现金流时不能将其判成滞销或质量稳定。 | 查下一季成品相对收入、DIO/DSO 和经营现金是否继续背离；不同模式不直接排名。 |

## 写入 v2 报告前的验收

- `overall` 用两三句：先交代盈利和放缓判断，再说最重要的支持/矛盾与 EPS 预期能否判定。
- `summary` 的三项互不重复：已实现盈利、未来预期、需求与交付条件。每项有证据，不重复总判断。
- 每个 `headline` 一句直说当前状态，`evidence` 交代日期和数字及局限，`watch` 最多两项观察。用了带日期的新证据，给能打开的有名称来源。
- “EPS 同比仍增但涨幅收窄”不是“盈利下降”；“H100 报价回升”不证明利用率上升；“订单增长”不证明接电。若一句话将任一前者写成后者，重写。
