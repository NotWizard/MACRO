# AI 算力全景：只读研究展示

## 用户确认的产品边界

本地Agent运行ai-compute-collect skill时采集数据、核验历史并撰写所有结论；页面只展示。没有网页采集/导入/模型调用，没有内置prompt或程序结论。未发布Agent报告就保留空位，不用旧模型文案填充。

## 继承的视觉系统

普通仪表盘扩展，不创建新视觉身份。保留现有Obsidian Blue/Paper色彩、系统字体、侧栏、ECharts与ChartTip，颜色来自frontend/src/design/tokens.css。页面不污染全站设计系统。

## 当前布局

模式为 Operate / Read：先读经营判断，再按需看证据。页面顶部为固定位置的经营总览和六个板块入口；默认总览直接展开总判断和三项依据，原文链接集中在「核验原文」。板块导航用带当前态的原生链接，继续支持 `#compute-earnings` 等旧链接与浏览器前进/后退。每次只挂载当前板块的一张图，不把六块纵向堆起来。

板块开头直接给出问题和覆盖全板块的短判断。观察公司用可见按钮，制造板块先露出常看公司，其余按环节展开，选中后收起并把该公司留在快捷栏；没有连续数据的公司注明原因并禁用。切换后在当前图位更新，离开再回来仍保留本次访问的公司及图表选择。盈利默认看 EPS、客户投入看单季 CapEx、制造先看戴尔的订单与排期。选择没有相应序列的公司时，主图显示缺口说明，其他图入口仍紧贴主图；电力容量仅在选中披露该指标的公司时显示。

至少两点的实际数据才进入趋势图和读数；单期披露、目标期指引、固定供应商当前价仍是研究输入。读数跟随当前图，图下来源可点入证据抽屉。网页始终保留已取得的完整历史，不设统一年份开关；EPS 不混全年与单季，缺期不伪连。金额、股数及 GPU 小时价沿用已有口径，不改取数规则。

主图旁是「下一步看什么」，详细证据和口径按需展开。报告 v2 仍由本地 Agent 填写 headline/evidence/watch，解读覆盖全板块，不随公司筛选改变；数据 hash 变化提示待复核，无报告没有程序回退。电力交期等非定期证据仍在解读中。

产业链联动靠内容和跳转表达：盈利看结果，客户投入看需求，制造看交付，租价观察市场条件，电力看部署约束，库存现金验证质量；不绘制主观因果箭头或综合分。各板块解读明确它与相邻证据怎样印证、何时不能互相替代。

租价板块不选公司，通过图表按钮切换 GetDeploying 挂牌周价和 SemiAnalysis 长期合成基准（H100 自 2023-10、A100 自 2023-06、B200 自 2025-06）。不同口径不拼接，保留原归属、历史与悬浮值。

## 响应与可访问性

桌面保留 216px 全站侧栏，板块导航吸顶、主图与解读并排；较窄时导航和公司按钮换行，图表、解读顺次阅读。按钮有选中态和可见焦点；展开制造分组后切公司，焦点回到快捷栏的当前公司。原生 dialog 保留焦点约束和 Escape 关闭。

## 验证范围

本轮验收重点：总览三项依据默认展开、板块直达和历史导航、快捷公司按钮、制造分组选中后回到图表、图表原位切换、来源抽屉、租价口径分离、亮暗与窄屏。

当前布局已用生产构建回读：1440、1024、768 与 390px 的盈利页均只渲染一张主图，切换 NVIDIA/AMD 不改变主图位置、不卡在原菜单；390px 的六个板块均无横向溢出，320px 展开制造分组仍可用。切换板块和公司不额外请求数据、没有写 API 请求。前端 56 项、算力后端 32 项测试通过。

此前已核验：393.67 亿美元的读数、悬浮值与抽屉一致；单点订单不进入趋势；SemiAnalysis 三条长期曲线的 2,913 个日期点均为独立来源，不与挂牌周价合并。
